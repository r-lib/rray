# rray: Array Helpers

Broadcast, reshape, reduce, and index base R arrays. Broadcasting
repeats axes with a dimension of one so that arrays with different
dimensions can be flexibly combined. Every function broadcasts its
inputs, so operations such as arithmetic, comparison, and combining work
consistently across axes.
