# Reshape

Running cost: $0.30

## Plan

Implement `rray_reshape()` which reshapes an array's dimension sizes without changing the underlying capacity (total number of elements).

## Implementation

Created:
- `src/reshape.c` / `src/reshape.h` — C implementation
- `R/reshape.R` — R wrapper with roxygen2 docs
- `tests/testthat/test-reshape.R` — 31 tests

Key design decisions:
- Early return (no copy) when dimension sizes already match
- Validates capacity is preserved, errors if not
- Uses `r_clone()` + set `dim` attribute (no data rearrangement needed since R is column-major)
- Drops all dimension names and names on reshape (same as R's `dim<-`)
- Reuses existing `check_dimension_sizes()` for input validation

All 131 tests pass.
