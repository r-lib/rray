# Switch to rlang C API

## Summary

Switched the C code from raw R API (`SEXP`, `Rf_*`, `R_NilValue`) to the rlang C library API (`r_obj*`, `r_length()`, `r_dim()`, `r_null`, `r_int()`, etc.).

## Changes

- `src/dimensionality.h`: `#include <Rinternals.h>` → `#include "rlang/rlang.h"`, `SEXP` → `r_obj*`, `R_xlen_t` → `r_ssize`
- `src/dimensionality.c`: Use `r_int()`, `r_dim()`, `r_null`, `r_length()` instead of raw R API equivalents
- `src/init.c`: `SEXP` → `r_obj*`, `R_NilValue` → `r_null`

All 10 tests pass, no compiler warnings.
