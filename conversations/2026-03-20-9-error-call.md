# Pass `error_call` through all C functions

Date: 2026-03-20

## Summary

Finished threading `error_call` (`struct r_lazy`) through all three exported C functions so that rlang error messages correctly attribute errors to the calling function.

## Changes

### R side
- `rray_dimension_sizes()`, `rray_dimensionality()`, `rray_capacity()` now pass `environment()` as a second arg to `.Call`. No `call` parameter exposed on the R side.

### C side
- All FFI wrappers (`ffi_rray_*`) now accept a `frame` parameter and construct `struct r_lazy error_call = { .x = frame, .env = r_null }` (forced lazy — frame is already the calling environment).
- All internal C functions (`rray_*`) now accept `struct r_lazy error_call` and pass it to `check_array()`.
- Headers updated to match new signatures.
- `init.c` updated: extern declarations and arg counts bumped from 1 to 2.

### Pattern
Follows the vctrs convention (e.g. `ffi_size()` in `src/size.c`): R passes `environment()`, C uses the frame directly as a forced lazy value with `r_null` env.

## Testing

All 41 tests pass. Snapshots updated — errors now show `Error in \`rray_dimension_sizes()\`:` etc.
