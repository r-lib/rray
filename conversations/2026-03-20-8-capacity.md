# Implement `rray_capacity()`

## Summary

Implemented `rray_capacity()` which returns the total number of elements in an array (the product of its dimension sizes).

## Files created/modified

- `src/capacity.c` — C implementation with `rray_capacity()` (returns `r_ssize`) and `ffi_rray_capacity()` FFI wrapper
- `src/capacity.h` — header declaring `rray_capacity()`
- `R/capacity.R` — R wrapper with roxygen2 docs
- `src/init.c` — registered the FFI function
- `tests/testthat/test-capacity.R` — tests for plain vectors, arrays, matrices, empty/zero-dim arrays, and error cases
- `man/rray_capacity.Rd` — generated docs
- `NAMESPACE` — updated export

## Key decisions

- Returns a double on the R side (not integer) since arrays can be large
- Uses `rray_dimension_sizes()` internally rather than duplicating the dim logic
- `KEEP()`/`FREE()` to protect the allocated dimension sizes object
- Updated CLAUDE.md with KEEP/FREE guidance
