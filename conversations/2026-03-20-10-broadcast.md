# Implement `rray_broadcast()`

## Goal

Implement `rray_broadcast(x, dimension_sizes)` that broadcasts an array to new
dimension sizes. Pure C implementation without xtensor, supporting all vector
types from `check_array()`.

## Approach

- C broadcasting algorithm using column-major index mapping
- For each output position, compute input position by clamping dimension indices
  where input size is 1
- Support: logical, integer, double, complex, character, raw, list
- Follow existing code patterns from dimension-sizes, capacity, etc.

## Files

- `src/broadcast.c` / `src/broadcast.h` - C implementation
- `R/broadcast.R` - R wrapper with roxygen docs
- `tests/testthat/test-broadcast.R` - tests covering all types
- Updated: `src/init.c`, `NAMESPACE`
