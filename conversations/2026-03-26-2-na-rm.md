# Add `na_rm` to `rray_sum()`

**Running cost: $0.25**

## Prompt

> Now lets add `na_rm` behavior as `rray_sum(x, axes, ..., na_rm = FALSE)`. At the C level we should have `rray_sum_lgl_one_na_rm()` as a helper and probably RRAY_FN_NA_RM_ONE and we should switch on na_rm outside the critical C for loop to preserve maximum performance.

## Changes

### R layer (`R/sum.R`)
- Added `...` (with `check_dots_empty0()`) and `na_rm = FALSE` parameters
- Pass `na_rm` through to `.Call(ffi_rray_sum, x, axes, na_rm, environment())`
- Updated roxygen docs with `@param ...` and `@param na_rm`

### C layer

**`src/sum.c`** — `ffi_rray_sum()` now takes 4 args (added `ffi_na_rm`), extracts `bool na_rm`, passes to `rray_sum()`. `rray_sum()` threads `na_rm` through type dispatch.

**`src/sum.h`** — Updated signature with `bool na_rm`.

**`src/sum-template.h`** — Added `RRAY_FN_NA_RM_ONE` macro per type. The hot loop branches on `na_rm` outside the loop (two separate loops) for maximum performance. Added four `_na_rm` helper functions:
- `rray_sum_lgl_one_na_rm()` — skips `NA_LOGICAL`
- `rray_sum_int_one_na_rm()` — skips `NA_INTEGER` (still checks overflow)
- `rray_sum_dbl_one_na_rm()` — skips `ISNAN(x)` (both NA and NaN)
- `rray_sum_cpl_one_na_rm()` — delegates to `rray_sum_dbl_one_na_rm()` per component

**`src/decl/sum-template-decl.h`** — Added forward declarations for the 4 `_na_rm` helpers.

**`src/init.c`** — Updated `ffi_rray_sum` extern and arg count from 3 to 4.

### Tests (`tests/testthat/test-sum.R`)
- `na_rm` removes integer NA
- `na_rm` removes double NA and NaN
- `na_rm` removes logical NA
- `na_rm` removes complex NA
- `na_rm` with all NA returns identity (0)
- `na_rm` with no NA matches default

All 69 tests pass.
