## Added `rray_dimension_names()`

User asked to add `rray_dimension_names()`, a function like `dimnames()` that always returns a list with length equal to the dimensionality of the array. Initially named `rray_names()`, then renamed to `rray_dimension_names()` to match `rray_dimension_sizes()`.

### Implementation

- `R/dimension-names.R` — exported R function with roxygen docs
- `src/dimension-names.c` / `src/dimension-names.h` — C implementation
- `tests/testthat/test-dimension-names.R` — 7 tests covering plain vectors, named vectors, arrays with/without dimnames, partial dimnames, 3d arrays, and error cases

### Logic

1. If `dimnames(x)` is non-NULL, return it directly
2. Otherwise, allocate a list of length `dimensionality(x)` (initialized to NULLs)
3. If `names(x)` is non-NULL, set it as the first element
4. Return the list
